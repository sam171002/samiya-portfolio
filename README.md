# Samiya Alam - Portfolio Website

Personal portfolio built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Tech Stack

- **Framework:** Next.js 14 (App Router), React, TypeScript
- **Styling:** Tailwind CSS with shared design tokens
- **Animation:** Framer Motion
- **Content:** Local JSON files in `/content`
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```


## Project Structure

```
app/                  # Next.js App Router pages and API routes
components/           # Section components (Hero, About, etc.)
content/              # JSON content files
lib/                  # Design system utilities (animations, fonts)
public/images/        # Optimized images
types/                # TypeScript content schemas
```
