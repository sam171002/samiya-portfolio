# Samiya Alam | Portfolio

This is my personal portfolio. It brings together production AI work, research, publications, certifications, and writing in a fast, editorial-style web experience.

[View the live portfolio](https://samiya-portfolio-ruby.vercel.app/)



## Technical Overview

- **Framework:** Next.js 15 App Router, React, TypeScript
- **UI:** Tailwind CSS, Framer Motion, responsive design tokens
- **Data:** Local content schemas with GitHub and Medium API routes
- **Images:** Next.js Image with local project, certification, and publication assets
- **Deployment:** Vercel

## Repository Structure

```text
app/                  Next.js routes and API endpoints
components/           Portfolio sections and reusable UI components
content/              Structured portfolio content
lib/                  Content accessors, animation utilities, and fonts
types/                 TypeScript content contracts
public/images/        Local visual assets
```

## Local Development

```bash
npm install
npm run dev
```
